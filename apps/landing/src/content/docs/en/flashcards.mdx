Flashcards give the ideas in your [pages](../pages/) another form: a prompt to recall, then an answer to check.

## Create a set

Open **Practice**, choose **Generate practice**, and select flashcards. Choose up to 20 source pages and add an optional focus. Generation runs through your ChatGPT connection and saves the resulting set.

You can create several sets with different source selections or instructions. The set is based on the page versions chosen at generation time.

## Review

Open the saved set. Try to recall the answer before revealing it with **Show answer** or Space. Then rate your recall: **Again**, **Hard**, **Good** or **Easy**. The number keys 1 to 4 select the same ratings after the answer is visible.

When reviewing within a subject, Study loads the cards due for that set. When no cards are due, you can choose **Replay flashcards** to work through the set again.

## Keep the material useful

Check the linked source pages if a card is unclear. Revise the page and generate a new set when you want your changes reflected in the cards. Archive sets you no longer use; the archive lets you preview and restore them.

For applying the same ideas in questions, try [practice exercises](../practice/).
