File processing and generation can continue while you work. Check the status in **Materials** or **Practice**.

<DocStep number={1} example="activity">
<header slot="intro">

## Follow the operation

Check the status before starting the same operation again.

</header>

In **Materials**, check the status next to the file. In **Practice**, watch the sidebar for quiz or flashcard generation and **Generation activity** for study notes. The notebook’s Assistant panel shows progress on its own requests.

An accepted request can still be waiting or running. You can keep using saved material while a new result is being prepared.

</DocStep>

<DocStep number={2} example="activity">
<header slot="intro">

## Stop or retry

Stop unwanted work or use the recovery action offered after a failure.

</header>

Use the stop or cancel action offered by the operation. Cancellation can take time; wait for the reported outcome rather than assuming the result from a click alone.

When work fails, read its explanation and use the available retry action. Check your ChatGPT connection for model work and the source status for file conversion. You can still consult the original file if extraction fails.

</DocStep>

<DocStep number={3} example="note">
<header slot="intro">

## Return to saved work

Come back to your saved material after work finishes.

</header>

Study keeps saved work and durable operation state in its database. After reopening the app, check the operation's current status before retrying. When selecting a note for generation, check that the notebook has saved your latest edits.

For the complete path, see [notes](../notes/), [study notes](../pages/) and [practice](../practice/).

</DocStep>
