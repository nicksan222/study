A source is material you bring to Study: a file, a link or an attachment to a [note](../notes/). The original file and the content Study reads from it serve different purposes. Keep the original available, and inspect the readable version before relying on it.

## Add material to a note

Attach the files that go with your notes. Study determines the file kind from its contents rather than trusting its extension. The note shows processing work and any failures beside the attachment.

Reading depends on the file kind and the available conversion capability. Do not assume that every stored file has readable text, or that every recording has a transcript. The app shows whether a source is ready and which action is available when it is not.

## Inspect what was read

Open the source to read its extracted content. Supported content has structured blocks and locations that can be used to check evidence. A file can be stored successfully even when reading it fails or is unavailable.

If processing fails, use the recovery action offered for that source. Keep the original file; an empty or failed extraction is not a completed page.

## Build study material

Select the sources you want to include when you [transform a note](../notes/#turn-the-note-into-a-page). Review the resulting [page](../pages/), then choose it when you [generate practice](../practice/).

This gives you a useful checkpoint: verify the readable source, revise the page, then practise from the version you chose.
