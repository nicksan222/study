Pages connect the notes you capture with the material you practise. A page can start as a blank page or be created from one or more saved notes.

## Create from your own material

In **Pages**, create a new page to write yourself, or choose **From notes**. Select the notes, then choose how to transform their saved notes and selected sources. Give the result a title and add any instructions.

You can ask for a clearer explanation, an organized summary or a combined account of several notes. The source selection matters: include the material you want the result to represent.

## Read and revise

Open a page to read its structured content. Use the page editor to make your own changes. Earlier versions remain available in the version controls; viewing an older version does not silently replace the current one. Use the explicit action to make an earlier version current when that is what you want.

Annotations attach to a particular passage. When you check evidence or return to an annotation, keep the selected version in mind: the same title can have several revisions.

## Combine pages

Select pages to merge them into one result. Give the new page a title and optional instructions. Check the resulting page before using it to study; the originals remain available if the merge fails.

## Make practice from pages

Open [Practice](../practice/) and choose **Generate practice**. Select up to 20 pages, choose exercises or flashcards, and add a focus if you want one.

Generation uses the selected page versions. If you later revise a page, create new practice when you want those changes reflected in the questions. Existing saved material is not a live view of every future edit.
