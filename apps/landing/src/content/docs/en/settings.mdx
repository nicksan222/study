Open **Settings** from the sidebar. Its navigation separates appearance, writing, reading, AI, practice and data. Use the settings search to find the relevant section.

## Language and appearance

Choose English or Italiano in the general settings. Appearance includes the color scheme, theme library, text size, contrast and panel animation controls. Choose the settings that make the workspace comfortable to read.

Sidebar settings adjust density, time display and document counts. These controls change how the workspace is presented, rather than changing your study content.

## Writing and reading

Writing settings include autosave timing, editor font size, spellcheck and whether Enter saves a note. Ctrl Enter (Cmd Enter on macOS) saves from the session composer regardless of the Enter preference.

Reading settings include reader font size and the default export format. Some numeric preferences have a **Save** action; use it to confirm the value and check any validation or save feedback.

## ChatGPT and AI behavior

The account section lets you sign in with ChatGPT or sign out. Complete browser sign-in when prompted, then return to Study.

Model settings select the model for each task tier. Instructions customize the available agents' rules. AI behavior includes automatic session titles, automatic answers to questions and the default level of detail.

Usage shows recorded model activity. Performance controls how much work can run in parallel and how much can wait in the queue.

## Practice defaults

Flashcard settings control how many new cards can enter your daily reviews. Quiz settings include question count, question types, shuffling, options per question and difficulty. Review these defaults when you want future practice to use a different format.

See [practice](../practice/) and [flashcards](../flashcards/) for how to use the resulting material.

## Subjects and data

Subject settings manage subject details. Data settings let you create a backup, inspect saved backups and import a backup. Review the preview and confirmation before restoring or removing data.

If a setting fails to load or save, use its retry action and check the reported result. Closing the dialog does not prove that a pending change was saved.
