Questi sono i tasti a cui risponde Study. Dove macOS usa Cmd, Linux e Windows usano Ctrl; le tabelle lo indicano dove c'è differenza.

## In tutta l'app

| Azione | macOS | Linux e Windows |
|---|---|---|
| Apri la ricerca | Cmd K | Ctrl K |
| Apri le impostazioni | Cmd , | Ctrl , |
| Schermo intero | F11, oppure Ctrl Cmd F | F11 |
| Testo più grande | Cmd + o Cmd = | Ctrl + o Ctrl = |
| Testo più piccolo | Cmd − | Ctrl − |
| Dimensione del testo predefinita | Cmd 0 | Ctrl 0 |

I tasti per la dimensione del testo funzionano anche mentre scrivi in un campo. Esc chiude un avviso aperto.

## Ricerca

| Azione | Tasto |
|---|---|
| Muoversi tra i risultati | ↑ e ↓ |
| Aprire il risultato selezionato | Invio |
| Chiudere la ricerca | Esc |

## Sessioni

| Azione | macOS | Linux e Windows |
|---|---|---|
| Inviare un appunto | Invio | Invio |
| Incollare file o un'immagine | Cmd V | Ctrl V |
| Uscire dalla casella di testo | Esc | Esc |
| Passare al controllo successivo o precedente | Tab o Maiuscolo Tab | Tab o Maiuscolo Tab |
| Muoversi nel menu di @study | ↑ e ↓ | ↑ e ↓ |
| Inserire la menzione | Invio o Tab | Invio o Tab |
| Chiudere il menu di @study | Esc | Esc |
| Scorrere le versioni di un messaggio | ← e → | ← e → |
| Annullare una modifica | Esc | Esc |

## Flashcard

Durante un ripasso:

| Azione | Tasto |
|---|---|
| Mostrare la risposta | Spazio o Invio |
| Di nuovo, Difficile, Bene, Facile | 1, 2, 3, 4 |

Mentre sfogli un mazzo:

| Azione | Tasto |
|---|---|
| Girare la flashcard, poi andare avanti | Spazio |
| Flashcard precedente o successiva | ← e → |

## Esercitazioni

| Azione | Tasto |
|---|---|
| Scegliere una risposta | La sua lettera, o il suo numero |
| Inviare una risposta scritta | Invio |
| Andare a capo in una risposta scritta | Maiuscolo Invio |
| Prossima domanda | Invio o Spazio |

## Schemi

| Azione | macOS | Linux e Windows |
|---|---|---|
| Spostarsi | Frecce, o trascina | Frecce, o trascina |
| Ingrandire | + o = | + o = |
| Ridurre | − o _ | − o _ |
| Zoom con il mouse | Cmd e rotellina | Ctrl e rotellina |
| Dimensione reale | 0 | 0 |
| Adattare alla vista | F, o doppio clic | F, o doppio clic |
