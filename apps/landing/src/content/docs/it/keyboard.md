Su macOS usa Cmd dove le tabelle indicano Cmd/Ctrl; su Linux e Windows usa Ctrl. Tab e Maiuscolo Tab passano tra i comandi e quello selezionato mantiene il comportamento consueto della tastiera.

## Ricerca nella barra laterale

| Azione                                              | Tasti      |
| --------------------------------------------------- | ---------- |
| Mostrare la barra laterale e attivare la ricerca    | Cmd/Ctrl K |
| Cancellare il campo di ricerca della barra laterale | Esc        |

## Scrittura nella nota

| Azione                  | Tasti          |
| ----------------------- | -------------- |
| Salvare un appunto      | Cmd/Ctrl Invio |
| Incollare dagli appunti | Cmd/Ctrl V     |

Le impostazioni di scrittura possono anche fare in modo che Invio salvi l'appunto. Con questa preferenza attiva, Maiuscolo Invio inserisce una nuova riga. L'azione **Salva appunto** resta disponibile accanto al riquadro.

## Ripasso delle flashcard

| Azione                                                                     | Tasti       |
| -------------------------------------------------------------------------- | ----------- |
| Mostrare la risposta                                                       | Spazio      |
| Valutare Di nuovo, Difficile, Bene o Facile dopo aver mostrato la risposta | 1, 2, 3 o 4 |

Le scorciatoie non interrompono la scrittura in un campo modificabile. Puoi anche usare i pulsanti visibili per mostrare la risposta e valutarla.

## Domande dei quiz

| Azione                                                      | Tasti          |
| ----------------------------------------------------------- | -------------- |
| Scegliere un'opzione numerata quando la domanda lo permette | Il suo numero  |
| Inviare una risposta valida a una domanda non aperta        | Invio          |
| Inviare una risposta scritta aperta                         | Cmd/Ctrl Invio |
| Aggiungere una riga in una risposta scritta aperta          | Invio          |

Le domande di abbinamento usano i loro comandi visibili al posto della scorciatoia per le opzioni numerate. Usa **Avanti** per proseguire dopo il commento.
