Una fonte è materiale che porti in Study: un file, un link o un allegato di una [nota](../notes/). Il file originale e il contenuto che Study ne legge hanno scopi diversi. Conserva l'originale e controlla la versione leggibile prima di usarla per studiare.

## Aggiungi materiale a una nota

Allega i file che accompagnano gli appunti. Study riconosce il tipo di file dal contenuto, senza fidarsi soltanto dell'estensione. La nota mostra il lavoro di elaborazione e gli eventuali errori accanto all'allegato.

La lettura dipende dal tipo di file e dalle capacità di conversione disponibili. Non dare per scontato che ogni file conservato abbia testo leggibile o che ogni registrazione abbia una trascrizione. L'app indica se una fonte è pronta e quale azione è disponibile quando non lo è.

## Controlla cosa è stato letto

Apri la fonte per leggere il contenuto estratto. Il contenuto supportato ha blocchi strutturati e posizioni utili per verificare le fonti. Un file può essere conservato correttamente anche se la lettura fallisce o non è disponibile.

Se l'elaborazione fallisce, usa l'azione di recupero offerta per quella fonte. Conserva il file originale: un'estrazione vuota o fallita non è una pagina completo.

## Costruisci il materiale di studio

Seleziona le fonti da includere quando [trasformi una nota](../notes/#trasforma-la-nota-in-un-pagina). Controlla il [pagina](../pages/) risultante e sceglilo quando [generi esercitazioni](../practice/).

Hai così un passaggio utile di verifica: controlla la fonte leggibile, rivedi la pagina e infine esercitati sulla versione scelta.
