Una fonte è materiale che porti in Study, per esempio un file o un link. Il file originale e il contenuto che Study ne legge hanno scopi diversi. Conserva l'originale e controlla la versione leggibile prima di usarla per studiare.

<DocStep number={1} example="sources">
<header slot="intro">

## Carica un file

Conserva l’originale in Materiali.

</header>

Apri **Materiali** e scegli **Carica materiale**. Study riconosce il tipo di file dal contenuto. Lo stato di elaborazione e gli eventuali errori compaiono accanto al file in Materiali.

La lettura dipende dal tipo di file e dalle capacità di conversione disponibili. Non dare per scontato che ogni file conservato abbia testo leggibile o che ogni registrazione abbia una trascrizione. L'app indica se una fonte è pronta e quale azione è disponibile quando non lo è.

</DocStep>

<DocStep number={2} example="sources">
<header slot="intro">

## Controlla cosa è stato letto

Controlla quello che Study ha potuto leggere prima di affidarti alla fonte.

</header>

Apri la fonte per leggere il contenuto estratto. Il contenuto supportato ha blocchi strutturati e posizioni utili per verificare le fonti. Un file può essere conservato correttamente anche se la lettura fallisce o non è disponibile.

Se l'elaborazione fallisce, usa l'azione di recupero offerta per quella fonte. Conserva il file originale per poterlo consultare.

</DocStep>

<DocStep number={3} example="page">
<header slot="intro">

## Costruisci il materiale di studio

Usa il materiale leggibile per generare appunti di studio o esercitazioni.

</header>

In **Esercitazioni**, seleziona i file da usare quando generi [appunti di studio](../pages/) o [esercitazioni](../practice/). Confronta gli appunti generati con i file originali e rivedili dove serve.

</DocStep>
